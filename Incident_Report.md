# Executive Summary

A Windows endpoint generated alerts indicating possible lateral movement activity.

A controlled lab simulation was conducted using legitimate Windows administration tools including Remote Desktop Protocol (RDP), PsExec, SMB Administrative Shares, Windows Remote Management (WinRM), and PowerShell Remoting.

Telemetry generated by Windows Security Event Logs and Microsoft Sysmon was investigated using Splunk Enterprise.

No malicious payloads were executed during this lab.

# Findings

The investigation confirmed the successful generation of multiple lateral movement techniques.

Windows Security Event Logs and Sysmon provided sufficient visibility into authentication events, remote administration activity, network connections, and process execution.

The observed activity matched expected laboratory behavior.

# Recommendations

Deploy Sysmon on all Windows endpoints.

Restrict RDP access.

Limit SMB Administrative Share access.

Monitor WinRM.

Enable PowerShell Logging.

Correlate authentication with process creation.

Deploy Wazuh.

Implement EDR.

---

# Final Verdict

This investigation successfully demonstrated how Windows Security Event Logs and Sysmon telemetry can be used to detect and investigate lateral movement techniques.

The simulated activity closely resembles attacker behavior while remaining safe for educational purposes.
